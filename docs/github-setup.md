## Full Description (for GitHub "About" or pinned readme excerpt)

> **ForgeAI** — Open-source prompt-to-live-URL generator. Turn a single sentence into a deployed, working website with database, forms, and custom domain — in ~15 seconds.

### Why ForgeAI?

- **Open-source** — MIT licensed, self-hostable, no vendor lock-in
- **BYOK** — Bring your own API keys (OpenRouter, HuggingFace, Supabase). You pay providers directly, we never see your keys
- **Ultra-cheap** — ~$0.002 per generation (50-100x cheaper than GPT-4o)
- **Full code ownership** — Export the entire Next.js project as ZIP
- **Config-driven** — Each component generated from strict specs with validation, not a giant blob of broken code
- **15,000+ templates** — Start from a template that already works, customize with a prompt
- **Plugin system** — Add your own AI models, deploy providers, templates, and components

### Stack
Next.js 14 · Tailwind CSS · shadcn/ui · Zustand · Hono · Supabase · OpenRouter · HuggingFace · Vercel · E2B
